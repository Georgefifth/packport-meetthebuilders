# Contract: slice

Written by the builder, reviewed by the evaluator BEFORE any code is written. Agree on what "done" means.
Each line is a behaviour the evaluator can check in a real browser or with a command. Use Given / When / Then.
Tick a box only when the evaluator's report says the behaviour passed.

## Scope
This contract covers the complete core workflow of **PackPort** on the main Customs Pre-Flight Workbench screen: first-run landing, the instant demo path across three preloaded APAC export SKUs, running the hybrid statutory + Google Gemini (`@google/genai`) inspection for Singapore (SFA), Australia (FSANZ), or Japan (CAA), inspecting numbered violations on the visual package proof, applying one-click regulatory fixes to generate a print-ready compliant export over-sticker, downloading the SVG sticker, and verifying empty state, bad-input error state, upstream fallback state, 390px mobile layout, and keyboard navigation.

## Checks
- [ ] Given a first-time visitor opens the landing page (`/`) at `1440x900` with no login and no API key, when the page finishes loading within 3 seconds, then the plain-language one-sentence pitch (`"Catch customs label violations and generate a print-ready Singapore, Australia, or Japan export over-sticker before your shipment leaves port"`), three labelled **Example SKU** buttons, the **Run Customs Pre-Flight** primary action button, and the default inspected dossier for **Example: Bali Crispy Prawn Sambal → Singapore (SFA)** are visible with zero console errors or failed network requests.
- [ ] Given a visitor on the landing page, when they click a different example SKU button (such as **Example: Chiang Mai Mango Drink → Australia (FSANZ)** or **Example: Saigon Matcha Oat Bar → Japan (CAA)**), then within 10 seconds `/api/inspect-label` returns 200 OK, the left-hand source label form populates with that SKU's ingredients, nutrition values, and destination market, and the right-hand dossier updates to show the destination market badge, **Customs Readiness Score** (`%` with plain-language meaning), customs verdict stamp (`Hold: Relabel Required`), and numbered violation pins (`1`, `2`, ...) on the visual package proof.
- [ ] Given an inspected SKU with customs violations, when the user views the **Statutory Findings** list, then each finding displays a plain-language severity badge (`Customs Hold (Must Fix)` or `Label Warning (Recommended Fix)`), the exact offending text from the label, the specific destination regulation clause (e.g., `Singapore SFA Food Regulations Reg 5` / `Eighth Schedule`, `FSANZ Standard 1.2.3 PEAL`, or `Japan CAA Food Labeling Standards`), a plain-language explanation of what fails at port, and an **Apply Fix** button.
- [ ] Given an inspected SKU with flagged customs violations, when the user clicks **Apply All Regulatory Fixes** (or clicks **Apply Fix** on each finding), then the live **Print-Ready Export Over-Sticker (88 mm × 112 mm)** SVG updates in place with inline-bolded mandatory allergens, a `Contains:` allergen summary line, international INS additive codes, a computed `Per 100g / 100mL` nutrition column, and compliant marketing copy, the **Customs Readiness Score** updates to `100% — Ready to print & ship`, and the customs verdict stamp changes to `Cleared for Export`.
- [ ] Given a user edits the source label form (changing the **Destination Market** selector, editing the **Ingredient List** text, or changing **Total Sugars per serving**) and clicks **Run Customs Pre-Flight**, then the inspection recalculates the per-100g/100mL nutrient values and statutory violations for the updated input and refreshes both the **Statutory Findings** list and the **Print-Ready Export Over-Sticker** SVG.
- [ ] Given a user viewing the **Print-Ready Export Over-Sticker**, when they click **Download Sticker SVG** or **Copy Customs Dossier**, then the browser triggers an `.svg` file download (or copies the 3-bullet customs summary text) and renders a visible confirmation status message (`"Downloaded compliant over-sticker SVG"` or `"Copied customs dossier to clipboard"`).
- [ ] Given a user on a mobile viewport (`390x844`), when they load `/` and complete the instant demo path and **Apply All Regulatory Fixes**, then `document.documentElement.scrollWidth` is `<= 390`, all interactive buttons have tap targets at least `44x44px` (or `>=40x32px` per probe), body text is at least `16px` (`>=14px` for secondary text, `>=12px` for labels), and the **Print-Ready Export Over-Sticker** SVG scales cleanly inside the viewport without horizontal clipping.
- [ ] Given a keyboard-only user starting at the top of `/`, when they press `Tab` through the example SKU buttons, form inputs, and action buttons and press `Enter` on **Run Customs Pre-Flight** (or on an example SKU button), then every focused control displays a visible `:focus-visible` outline (`>=2px` contrast ring), tab order follows visual reading order, and pressing `Enter` triggers the inspection.

## Edge cases
- [ ] Given a user clicks **Clear Form** to reset the workbench to its empty state, when the form is cleared, then the right-hand dossier displays the empty-state prompt (*"Enter your product's ingredients and nutrition values on the left, or click one of the 3 Example APAC SKUs above to run an instant inspection"*) with quick-start buttons to load an example SKU.
- [ ] Given a user clears the **Ingredient List** field (leaving it blank) or enters `0` or a negative number in **Serving Size (g/mL)**, when they click **Run Customs Pre-Flight**, then an inline plain-language error message appears next to the invalid field (e.g., *"Please enter at least one ingredient on the label"* or *"Serving size must be greater than 0g"*), keyboard focus moves to that field, and all other typed form fields remain intact.
- [ ] Given the backend `/api/inspect-label` endpoint is called when `GEMINI_API_KEY` is unset or when upstream failure is simulated (`POST /api/inspect-label?simulateError=1`), when the user clicks **Run Customs Pre-Flight**, then the deterministic APAC statutory rule engine completes the inspection, displays a plain-language notice (*"Completed inspection using the built-in statutory rule engine so your work is safe"*), and renders the full findings and export over-sticker without throwing an unhandled error.

## Not in this contract
- User authentication, account registration, or paid subscription checkout.
- Wet-lab chemical assay calculation from raw agricultural recipes.
- Direct EDI submission to customs brokerage portals (TradeNet Singapore / ICS Australia).
