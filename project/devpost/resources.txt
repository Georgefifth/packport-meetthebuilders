Resources & Technical Stack — Meet the Builders 2026 (Google Cloud Gen AI Academy APAC Edition)

=== SPONSOR / REQUIRED GOOGLE AI TOOLS ===
Submissions must use Google AI / Google Cloud technologies and provide "3 bullets on the Google AI tools you used (Gemini API, Vertex AI, Gemma, Firebase Genkit...)".
Highlighted tools across the program:
1. Gemini API / Google AI Studio (`@google/genai` / Gemini 2.5 Flash / Pro)
2. Agent Development Kit (ADK) — single-agent & multi-agent orchestration
3. Model Context Protocol (MCP) — connecting AI agents to external tools, APIs, and databases
4. Google Cloud Run — serverless container deployment for AI agents and web apps
5. Vertex AI / Gemma / Firebase Genkit — multimodal reasoning, structured outputs, agent workflows
6. AlloyDB for PostgreSQL / BigQuery / Cloud Firestore — data storage and analytics

=== CORE TRACKS & CODELABS FROM GEN AI ACADEMY APAC 2026 ===
- Track 1: Build and deploy AI agents using Gemini, ADK, and Cloud Run
  * Codelab 1: Build and deploy an ADK agent on Cloud Run
  * Codelab 2: Building AI Agents with ADK: The Foundation
  * Lab: Build an AI Agent on Cloud Run with ADK and RAG
- Track 2: Connect AI agents to real-world data and tools using Model Context Protocol (MCP)
  * Codelab 1: Build a Location Intelligence ADK Agent with MCP servers for BigQuery and Google Maps
  * Codelab 2: MCP Toolbox for Databases: Making BigQuery datasets available to MCP clients
  * Lab: Optimize Shop Placement with Gemini and BigQuery
- Track 3: Build AI-powered applications & productivity agents
  * Codelab 1: AlloyDB Quick Setup
  * Codelab 2: Building a Real-Time Surplus Engine with Gemini 3 Flash & AlloyDB
  * Lab: Deploy Personal Productivity Assistant using Cloud Run
