## Judging criteria
From the official Gen AI Academy APAC 2026 Hackathon & Ideathon evaluation framework (`project/devpost/rules.txt`):

| Criterion | Weight | Question judges are told to ask |
| :--- | :--- | :--- |
| **1. Solution quality & functionality (Usability & Stability)** | **20%** | Does the application actually run reliably (`Stability`), and does it solve a real problem for a real user (`Usability`) with working end-to-end functionality? |
| **2. Architecture & technical execution** | **20%** | How effectively and cleanly does the solution integrate Google AI / Google Cloud technologies (Gemini API, Vertex AI, ADK, MCP, Cloud Run, structured outputs)? |
| **3. Impact & use case relevance** | **20%** | Does it address a concrete, meaningful local, regional, or operational problem in APAC with measurable value for the target users? |
| **4. Technical choices, feasibility & security (Authenticity & Security)** | **20%** | Is the work original (`Authenticity`), are the technical choices feasible for production, and is it built responsibly (`Security` — no hardcoded secrets, safe handling of inputs)? |
| **5. Demo, UX & presentation** | **20%** | Is the UI/UX immediately clear, and does the <= 90-second demo video clearly introduce the builder, state the problem, show the working solution, and explain who it helps? |

Path 02 requires our public GitHub repository URL, a <= 90-second demo video (< 15 MB), 3 bullets detailing our Google AI tools (Gemini API / `@google/genai`, structured multi-agent/tool workflows, and Cloud Run-ready architecture), and a `#Meetthebuilders` social post. The jury consists of Google Cloud Solutions Consultants, Principle Architects, Developer Advocates, and AI Engineers (`Kenrick Tandrian`, `Taewoo Kim`, `Thu Ya K.`, `Abirami Sukumaran`, `Catherine Wang`, `Sharmila Devi`, `Faisal Hadiputra`), who prioritize practical APAC problem-solving, clean Gemini API / agentic tool execution, zero hardcoded secrets, and an immediately usable live product over slideware.

**What past Meet the Builders Hall of Fame & Cohort winners had in common (5 observations from `project/devpost/updates.txt`):**
1. **A concrete, named frontline user and high-stakes daily problem:** Winners like *SafeSight* (workplace hazard inspector issuing stop-work alerts), *AgriGrade* / *Yield Guard* (crop grading & yield protection), and *Property Inspection AI* solved a specific job for a specific person rather than offering a generic chat wrapper.
2. **Immediate visual or structured evidence in the first 10 seconds:** Every featured Hall of Fame project (*AI Movie Companion*, *Batch Lens*, *TrueSite*, *SafeSight*) accepted a real input (or instant sample scenario) and returned structured, inspectable outputs (risk scores, annotated findings, action plans) rather than walls of markdown.
3. **Clear multi-step Google AI / agentic orchestration (`Analytics` + `Multi-Agent`):** Every single featured Hall of Fame project on the APAC showcase was tagged with `Analytics` and `Multi-Agent`, showing distinct reasoning steps (ingest/inspect -> analyze/verify -> actionable output) powered by Gemini.
4. **Zero-friction live demo with real domain data:** Cohort Performance Excellence winners (*WeLumaAI* for Best use of Google APIs, *Personal Gemini Journal* for Intuitive data visualization, *Untangled* for Human-centered safety design) worked immediately in the browser with realistic preloaded scenarios so judges could test in one click.
5. **Explicit, verifiable Google AI tool attribution:** Winners clearly documented their exact Google AI building blocks (Gemini API structured outputs, multimodal/document analysis, agent tool calling, and serverless deployment) in three crisp bullets that matched the codebase.
